I think one thing I have really come to enjoy with having my own site is just the flexibilty and freedom to put things however I desire. Social media is way too limiting. I also really hate using like website builders like squarespace or wordpress. I find that I can never truely have the website how I wanted formatted there. With html, css and javascript its just much more control then you would ever get with a drop and drag website builder. I know its something that is more accessable to computer illiterate folks, but for a tech nerd like myself it I love that i can use do this.
